# TaskFlo Admin Dashboard 👑

لوحة إدارة النظام والمستخدمين الخاصة بـ **TaskFlow Pro** — مربوطة بنفس مشروع Firebase (`taskflow-ad5fe`).

> Static site (HTML + JS, no build). Live at: **https://abdelrahmanshoaib.github.io/taskflo-admin/** (فعّل GitHub Pages من الريبو لو الرابط مش شغال)

## المميزات

- 👑 دخول الأدمن فقط (إيميل + UID مطابق — غير كده بيترفض)
- 📊 إحصائيات: المستخدمون / نشط اليوم / إجمالي المهام / اشتراكات نشطة
- 👥 جدول المستخدمين: بحث + آخر ظهور + عدد المهام + حالة الاشتراك + تعديل (الخطة/ميعاد الانتهاء/تفعيل)
- 📢 إدارة إعلانات الصفحة الرئيسية (نشر/إظهار/حذف)

## الإعداد (مرة واحدة)

1. القواعد في `firestore.rules` (فيها قراءة الأدمن للإحصائيات) → الصقها في **Firestore → Rules → Publish**
   - ⚠️ ملاحظة خصوصية: القواعد دي تسمح للأدمن (UID فقط) بقراءة داتا المستخدمين لغرض الإحصائيات. الكتابة للمستخدم نفسه فقط (مع شرط الاشتراك).
2. افتح رابط الداشبورد وسجل دخول بإيميل وكلمة سر الأدمن.

## الربط مع الإكستنشن

- نفس الـ `apiKey/projectId` (في `config.js`) — أي تغيير هناك ينعكس هنا فوراً.
- من تبويب **👑 الإدارة** في الإكستنشن: زرار **🌐 لوحة الإدارة الكاملة** يفتح الداشبورد دي.
- الاشتراكات المعدلة هنا تُطبق على الإكستنشن فوراً (بتوقيت السيرفر عبر القواعد).
